
<ComponentPreview name="sheet-basic" />

## 结构

```tsx
import {Button, Sheet} from "@heroui/react";

export default () => (
  <Sheet>
    <Sheet.Trigger>
      <Button variant="secondary">打开面板</Button>
    </Sheet.Trigger>
    <Sheet.Backdrop>
      <Sheet.Content>
        <Sheet.Dialog>
          <Sheet.Handle />
          <Sheet.CloseTrigger aria-label="关闭面板" />
          <Sheet.Header>
            <Sheet.Heading>详情</Sheet.Heading>
          </Sheet.Header>
          <Sheet.Body>面板内容</Sheet.Body>
          <Sheet.Footer>
            <Sheet.Close>
              <Button variant="secondary">完成</Button>
            </Sheet.Close>
          </Sheet.Footer>
        </Sheet.Dialog>
      </Sheet.Content>
    </Sheet.Backdrop>
  </Sheet>
);
```

`Sheet.Root` 是 `Sheet` 的别名。将 `Sheet.Trigger` 直接放在根组件内，并包裹一个可按压元素（如 `Button`）。通过 `Sheet.Heading`、`aria-label` 或 `aria-labelledby` 为对话框提供无障碍名称。使用 `Sheet.Close`、`Sheet.CloseTrigger` 或带有 `slot="close"` 的按钮支持键盘关闭；拖动手柄对辅助技术隐藏。

## 示例

### 位置

根组件的 `placement` 支持 `bottom`（默认）、`top`、`left` 和 `right`。

<ComponentPreview name="sheet-placements" />

### 吸附点

数字表示**像素**，而不是比例。字符串表示 CSS 长度；百分比相对于面板尺寸。面板初始停留在第一个吸附点，完整展开位置始终隐式存在。末尾的 `1`、`"1"` 或 `"100%"` 会被忽略。其他数字仍以像素为单位。

<ComponentPreview name="sheet-snap-points" />

### 连续吸附点

一次滑动可以跨越多个吸附点。完全展开位置隐式存在，无需额外的连续吸附属性。

<ComponentPreview name="sheet-snap-points-sequential" />

### 背景渐变吸附点

经过部分展开的吸附点时，背景保持透明；越过最后一个吸附点并继续展开时，背景逐渐显现。此行为由 React Aria 管理，不支持 `fadeFromIndex`。

### 禁止手势关闭

`isDismissable={false}` 阻止点击外部、Escape 和滑动关闭。显式关闭按钮仍然可用。

<ComponentPreview name="sheet-non-dismissable" />

### 可滚动内容

在部分展开时，滑动会展开面板；完全展开后，`Sheet.Body` 才滚动内部内容。`Sheet.Handle` 也支持鼠标拖动。

<ComponentPreview name="sheet-scrollable-content" />

### 悬浮面板

`isDetached` 在屏幕边缘与面板之间添加间距，并将所有角设为圆角。

<ComponentPreview name="sheet-detached" />

### 受控状态

组合使用 `isOpen` 和 `onOpenChange`，或用 `defaultOpen` 设置非受控初始状态。受控面板可以省略 `Sheet.Trigger`。

<ComponentPreview name="sheet-controlled" />

### 拖动手柄

手柄提供可见的拖动提示，并支持指针拖动。面板完全展开前，触摸滑动也可作用于面板本身，并不限于手柄区域。

<ComponentPreview name="sheet-handle-only" />

### 嵌套面板

将 `Sheet.NestedRoot` 放在另一个面板内。React Aria 管理堆叠和焦点恢复，只有最底层面板使页面背景变暗。

<ComponentPreview name="sheet-nested" />

### 职业选择器

在初始吸附点为 355px 的面板中组合搜索框和虚拟列表。选择职业后更新所选值并关闭面板。

## 自定义

通过各部分的 `className` 或 `@layer components` 中的 `sheet__*` BEM 类自定义样式。保留 React Aria 的滚动定位，不要叠加独立的位移动画。

### Tailwind CSS

通过 `className` 为各部分添加 Tailwind CSS 工具类。

```tsx
<Sheet>
  <Sheet.Trigger>
    <Button variant="secondary">打开面板</Button>
  </Sheet.Trigger>
  <Sheet.Backdrop>
    <Sheet.Content className="mx-auto max-w-lg">
      <Sheet.Dialog className="rounded-t-3xl border border-border">
        <Sheet.Handle />
        <Sheet.CloseTrigger aria-label="关闭面板" />
        <Sheet.Header className="text-center">
          <Sheet.Heading>详情</Sheet.Heading>
        </Sheet.Header>
        <Sheet.Body className="px-6 pb-6">面板内容</Sheet.Body>
      </Sheet.Dialog>
    </Sheet.Content>
  </Sheet.Backdrop>
</Sheet>
```

### 全局 CSS

使用 `@layer components` 自定义 Sheet 的 BEM 类。

```css
@layer components {
  .sheet__dialog {
    @apply border border-border;
  }

  .sheet__header {
    @apply text-center;
  }

  .sheet__body {
    @apply px-6 pb-6;
  }
}
```

## 样式参考

HeroUI 使用 [BEM](https://getbem.com/) 命名规范，使组件样式易于复用和自定义。

### CSS 类

#### 基础类 [!toc]

- `.sheet__overlay` - 模态遮罩容器
- `.sheet__backdrop` - 面板后方的背景遮罩
- `.sheet__content` - 控制面板尺寸与堆叠的容器
- `.sheet__dialog` - 对话框表面
- `.sheet__header` - 头部区域
- `.sheet__heading` - 对话框标题
- `.sheet__body` - 完全展开后可滚动的内容区域
- `.sheet__footer` - 底部操作区域
- `.sheet__handle` - 可拖动的手柄区域
- `.sheet__handle-bar` - 默认手柄指示条
- `.sheet__close-trigger` - 关闭按钮

#### 背景变体 [!toc]

- `.sheet__backdrop--opaque` - 暗色遮罩（默认）
- `.sheet__backdrop--blur` - 模糊背景遮罩
- `.sheet__backdrop--transparent` - 透明背景遮罩

嵌套时，仅最底层面板显示背景遮罩。

#### 位置变体 [!toc]

- `.sheet__content--bottom`, `.sheet__dialog--bottom` - 底部（默认）
- `.sheet__content--top`, `.sheet__dialog--top` - 顶部
- `.sheet__content--left`, `.sheet__dialog--left` - 左侧
- `.sheet__content--right`, `.sheet__dialog--right` - 右侧

### 交互状态

- `[data-focus-visible="true"]` - 关闭按钮的键盘焦点；原生回退选择器为 `:focus-visible:not([data-focused])`
- `:hover`, `[data-hovered="true"]` - 关闭按钮悬停
- `:disabled`, `[aria-disabled="true"]` - 关闭按钮禁用
- `[data-dragging]` - 正在拖动手柄
- `[data-expanded]` - 面板完全展开，启用内容滚动
- `[data-has-descendants]` - 存在已打开的嵌套面板
- `[data-detached]` - 面板与边缘留有间距，并使用圆角
- `[data-snap-points]` - 面板配置了部分展开吸附点
- `[data-entering]`, `[data-exiting]` - 打开与关闭的生命周期状态
- `[data-closed]` - 保留的已关闭遮罩，禁用指针交互

### 数据属性

DOM 部分提供以下 `data-slot`：`sheet-overlay`、`sheet-backdrop`、`sheet-content`、`sheet-dialog`、`sheet-header`、`sheet-heading`、`sheet-body`、`sheet-footer`、`sheet-handle`、`sheet-handle-bar` 和 `sheet-close-trigger`。根组件、Trigger 和 Close 不添加 DOM 元素。

`Sheet.Content` 还提供 `data-placement`、`data-detached` 和 `data-snap-points`。React Aria 在相应部分提供 `data-position`、`data-expanded`、`data-stack-index`、`data-has-descendants`、`data-entering` 和 `data-exiting`。

## API 参考

### Sheet / Sheet.Root / Sheet.NestedRoot

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 组合部分。 |
| `isOpen` | `boolean` | — | 受控打开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控初始状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 请求打开或关闭时调用。 |
| `onClose` | `() => void` | — | 请求关闭时调用。 |
| `onAnimationEnd` | `(open: boolean) => void` | — | 进入或退出结束后调用。 |
| `placement` | `"bottom" \| "top" \| "left" \| "right"` | `"bottom"` | 屏幕的物理边缘。 |
| `isDismissable` | `boolean` | `true` | 允许外部交互、Escape 和滑动关闭。 |
| `isDetached` | `boolean` | `false` | 面板与屏幕边缘保持间距。 |
| `snapPoints` | `(number \| string)[]` | — | 部分展开的吸附位置；完整展开位置隐式存在。 |

`Sheet.NestedRoot` 必须在父 Sheet 内使用。根组件的 `isNested` 为内部标记；嵌套时使用 `NestedRoot`。

### 组合部分

| 部分 | 属性与行为 |
| --- | --- |
| `Trigger` | 一个可按压的 React 元素。 |
| `Close` | 一个可按压的 React 元素；保留其 `onPress` 回调。 |
| `Backdrop` | React Aria SheetOverlay 属性，但排除根组件控制的状态、位置、吸附点和 `style`；提供字符串 `className`、`children`、`variant="opaque" \| "blur" \| "transparent"` 和 `isExiting`。 |
| `Content` | React Aria Sheet 属性；字符串 `className`；children 可为接收面板状态的函数。HeroUI 提供默认堆叠动画和 overscroll padding。 |
| `Dialog` | React Aria SheetContent 属性，children 为 ReactNode；转发 ref 和无障碍属性。 |
| `Heading` | React Aria Heading 属性；默认 `slot="title"`。 |
| `Header`、`Body`、`Footer`、`Handle` | div 属性和 ref；Handle 无 children 时渲染默认手柄条。 |
| `CloseTrigger` | CloseButton 属性与字符串 `className`；保留使用者的 `onPress`。 |

`Backdrop.isExiting` 在关闭后保留内容，直到清除此标记。关闭仍会释放模态焦点限制和页面滚动锁定。不再需要保留内容时，请清除此标记。

命名导出包括 `SheetRoot`、`SheetTrigger` 等各部分、对应的属性类型、`SheetProps`、`SheetNestedRootProps`、`sheetVariants` 和 `SheetVariants`。组合属性类型使用索引访问，例如 `Sheet["Props"]` 和 `Sheet["ContentProps"]`。

## Sheet 与 Drawer

Sheet 使用 React Aria 原生滚动手势，支持部分吸附位置和嵌套堆叠。Drawer 保留原有 API 和行为；新增 Sheet 不会迁移或弃用 Drawer。
