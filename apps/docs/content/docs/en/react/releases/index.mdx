## Latest Release

### v3.2.7

**October 14, 2026**

React Aria upgrade: bumps `react-aria-components` to `1.22.1` (`react-aria@3.53.1`). Components reduce rendering overhead by memoizing stable styles and avoiding unnecessary render-prop class-name work. [CloseButton](/docs/components/close-button) preserves slot-provided `aria-label`s, overlays open and close faster on mid-range phones, [Dropdown](/docs/components/dropdown) menus stay usable on narrow screens, field variants keep their fill under browser autofill, and [Toast](/docs/components/toast) layout is fixed on iOS Safari and inside expanded stacks. Also includes fixes for list popovers, pickers, [Calendar](/docs/components/calendar), [AvatarGroup](/docs/components/avatar-group), [Checkbox](/docs/components/checkbox), and [ScrollShadow](/docs/components/scroll-shadow).

[Read full release notes →](/docs/react/releases/v3-2-7)

### v3.2.6

**September 17, 2026**

Patch release: [AvatarGroup](/docs/components/avatar-group) returns as a dedicated component, focus rings are keyboard-only again on [ListBox](/docs/components/list-box), [Dropdown](/docs/components/dropdown), [Select](/docs/components/select), and overlay triggers after a mouse-driven open, `@internationalized/date` moves to `peerDependencies` while `tailwind-merge` and `@react-aria/i18n` are dropped, [ColorSlider](/docs/components/color-slider) no longer warns on every render in production, bare `.tag` markup keeps its default padding, [Breadcrumbs](/docs/components/breadcrumbs) sit back on the spacing grid, and React Aria is upgraded to `1.21.1` (`react-aria@3.52.1`). Context values are also memoized across 43 components, so consumers no longer re-render on every root render.

[Read full release notes →](/docs/react/releases/v3-2-6)

**September 8, 2026**

Also fixes theme tokens in nested `data-theme` scopes and shadow DOM, native `:focus-visible` rings on exported variants, and modal-level overlays being covered by closing popovers, plus [ScrollShadow](/docs/components/scroll-shadow), [Table](/docs/components/table), [Drawer](/docs/components/drawer), [NumberField](/docs/components/number-field), [Accordion](/docs/components/accordion), [Label](/docs/components/label), and [Tag](/docs/components/tag).

## Previous Releases

### v3.0.0-alpha.35

**October 21, 2025**

#### React Server Components Support
- Fixed critical issue where compound components didn't work in React Server Components (RSC)
- Moved compound pattern logic from components to index files, resolving `"use client"` conflicts
- **(⚠️ Breaking change)**: Main component now requires `.Root` suffix (e.g., `<Avatar>` → `<Avatar.Root>`)
- Named exports remain unchanged and fully supported

#### React 19 Improvements
- Removed `forwardRef` (now native in [React 19](https://react.dev/blog/2024/12/05/react-19#ref-as-a-prop))
- Simplified Context usage (`Context.Provider` → [React 19](https://react.dev/blog/2024/12/05/react-19#context-as-a-provider))

#### Switch Component Refactoring
- **(⚠️ Breaking change)**: Split Switch and SwitchGroup into separate components
- Cleaner API: `<SwitchGroup>` replaces `<Switch.Group>` and `<Switch.GroupItems>`
- Matches Radio/RadioGroup pattern for consistency
- Separate styles, types, and implementations

#### Affected Components
All compound components now require `.Root` suffix: `Accordion`, `Avatar`, `Card`, `Disclosure`, `Fieldset`, `Kbd`, `Link`, `Popover`, `Radio`, `Switch`, `Tabs`, `Tooltip`

[Read full release notes →](/docs/react/releases/v3-0-0-alpha-35)
