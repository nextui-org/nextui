React Aria upgrade: HeroUI bumps `react-aria-components` to `1.22.1` (`react-aria@3.53.1`). [CloseButton](/docs/components/close-button) no longer hardcodes `aria-label="Close"`, so slot-provided labels (for example the localized [Toast](/docs/components/toast) close control) are preserved. Overlays open and close faster on mid-range phones, secondary [Input](/docs/components/input) and grouped fields keep their variant fill under browser autofill, and [Toast](/docs/components/toast) layout is fixed on iOS Safari and when spawning toasts inside an expanded stack. This release also nests [Select](/docs/components/select), [Dropdown](/docs/components/dropdown), [Autocomplete](/docs/components/autocomplete), and [ComboBox](/docs/components/combo-box) popover radii with item padding, keeps picker indicators off short labels, aligns [Dropdown](/docs/components/dropdown) submenu padding and section trigger icons, keeps [Calendar](/docs/components/calendar) weekday headers in equal columns, and includes the v3.2.6 follow-up fixes for [AvatarGroup](/docs/components/avatar-group), [Checkbox](/docs/components/checkbox), and [ScrollShadow](/docs/components/scroll-shadow).

## Dependencies

- **React Aria**: Upgrade to [React Aria 1.22.1](https://react-aria.adobe.com/releases/v1-22-0) — `react-aria-components@1.22.1`, `react-aria@3.53.1`, `react-stately@3.51.0`, `@react-types/shared@3.37.0`, and `@internationalized/number@3.6.9` ([#6939](https://github.com/heroui-inc/heroui/pull/6939), [#6949](https://github.com/heroui-inc/heroui/pull/6949)).
- **Security**: Patch open Dependabot alerts in transitive dependencies ([#6938](https://github.com/heroui-inc/heroui/pull/6938)).

## Bug Fixes

- **CloseButton**: Stop hardcoding `aria-label="Close"` on the React Aria `Button`. Explicit `aria-label` props and slot context labels (toast `close`, search field `clear`, tag `remove`) are no longer overridden ([#6946](https://github.com/heroui-inc/heroui/pull/6946)).
- **Toast**: Collapse the bottom-region anchor on iOS Safari so stacked toasts sit flush with the safe area ([#6936](https://github.com/heroui-inc/heroui/pull/6936)). Replace `useMediaQuery` action placement with a CSS grid layout ([#6932](https://github.com/heroui-inc/heroui/pull/6932)). Measure stack height with `offsetHeight` instead of `scrollHeight` so the indicator stays aligned with the title when spawning toasts inside an expanded stack ([#6952](https://github.com/heroui-inc/heroui/pull/6952)).
- **Dropdown**: Align submenu item start padding with the menu padding scale ([#6941](https://github.com/heroui-inc/heroui/pull/6941)). Center the trigger icon in the with-sections example ([#6944](https://github.com/heroui-inc/heroui/pull/6944)).
- **Calendar**: Keep weekday header labels in equal columns ([#6925](https://github.com/heroui-inc/heroui/pull/6925)).
- **Overlays**: Speed up open and close on mid-range phones. Overlay enter and exit animate opacity and transform only (no `filter` keyframes), touch devices skip `backdrop-filter` on blurred modal and drawer scrims, WebKit keeps popovers mounted until the close animation is running, coarse pointers show [Dropdown](/docs/components/dropdown) menus as soon as they are placed instead of waiting on a keyboard check, and a swiped-away [Drawer](/docs/components/drawer) clears inline `transition: none` so the exit transition runs ([#6934](https://github.com/heroui-inc/heroui/pull/6934)).
- **List popovers**: Nest the outer radius with the item padding on [Select](/docs/components/select), [Dropdown](/docs/components/dropdown), [Autocomplete](/docs/components/autocomplete), and [ComboBox](/docs/components/combo-box) ([#6916](https://github.com/heroui-inc/heroui/pull/6916)).
- **Picker indicators**: Keep the checkmark off the label in [Select](/docs/components/select), [ComboBox](/docs/components/combo-box), and [Autocomplete](/docs/components/autocomplete) popovers ([#6908](https://github.com/heroui-inc/heroui/pull/6908)).
- **AvatarGroup**: Clip overlap follows the avatar radius ([#6884](https://github.com/heroui-inc/heroui/pull/6884)).
- **Checkbox**: Keep the checkmark SVG mounted so the draw animation no longer flashes when toggling indeterminate selection in [Table](/docs/components/table) ([#6890](https://github.com/heroui-inc/heroui/pull/6890)).
- **ScrollShadow**: Remove the mask seam at fractional device pixel ratios ([#6914](https://github.com/heroui-inc/heroui/pull/6914)).
- **Radio**: Pair `:focus-visible`, `:hover`, and `:active` with the existing `data-*` state rules on [Radio](/docs/components/radio) ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).
- **Toast styles**: Pair `data-*` attributes with `:focus-visible` and `:hover` rules ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).

## Styles

- **Field autofill**: Keep `variant="secondary"` (and other variants) on [Input](/docs/components/input), [TextArea](/docs/components/textarea), [InputGroup](/docs/components/input-group), [SearchField](/docs/components/search-field), [NumberField](/docs/components/number-field), and [ComboBox](/docs/components/combo-box) when the browser autofills values. Autofill rules now read each variant's fill token and use an inset `box-shadow` cover in Chromium instead of hardcoding primary field colors ([#6943](https://github.com/heroui-inc/heroui/pull/6943)).
- **Disclosure**: Remove a stray `.accordion__heading` rule from `disclosure.css` ([#6904](https://github.com/heroui-inc/heroui/pull/6904)).
- **Chip**: Empty `.chip--md` — it re-declared the `text-xs` already on the base `.chip` class ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).

## Components
